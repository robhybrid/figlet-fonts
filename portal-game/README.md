# Portal Chambers

A browser homage to Valve’s **Portal** — first-person test chambers with a dual-portal gun, momentum travel, and weighted companion cubes.

> Fan-made tribute. Not affiliated with or endorsed by Valve.

## Run

From the repository root:

```bash
npm run portal-game
```

Open [http://localhost:4174/portal-game/](http://localhost:4174/portal-game/).

## Controls

| Input | Action |
| --- | --- |
| Mouse | Look (click to capture) |
| `W` `A` `S` `D` | Move |
| `Space` | Jump |
| Left click | Fire blue portal |
| Right click | Fire orange portal |
| `E` | Grab / drop cube |
| `R` | Reset chamber |
| `Esc` | Release mouse |

### Phone / tablet

On-screen controls appear automatically on touch devices (no mouse capture needed):

| Input | Action |
| --- | --- |
| Left stick | Move |
| Drag on the right side | Look |
| **Blue** / **Orange** | Fire portals |
| **Jump** | Jump |
| **Grab** | Pick up / drop cube |
| **Reset** | Restart the chamber |

## Chambers

1. **00** — Place linked portals and walk through
2. **01** — Floor–ceiling fling onto a ledge
3. **02** — Cube on a button opens the door
4. **03** — Portal the cube into a sealed room
5. **04** — Tall fling to the high exit

Portals only stick to lighter paneled surfaces. Dark / striped walls are non-portalable.
