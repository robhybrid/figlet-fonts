# Baby Boot — Stress Relief Game

A mobile-friendly browser game. Cartoon babies bounce around the screen — swipe through them to boot them away and lower your stress meter.

## Play

Open `index.html` in a mobile browser, or serve locally:

```bash
cd baby-kick-game
python3 -m http.server 8080
```

Then visit `http://localhost:8080` on your phone or desktop.

## Controls

- **Mobile:** Swipe across the screen to kick babies
- **Desktop:** Click and drag to kick

## Goal

- Kick babies to earn points and build combos
- Each kick lowers your **Stress** meter
- Reach **0% stress** to enter Zen Mode

## Disclaimer

This is a satirical stress-relief game with cartoon characters. No babies were harmed in the making of this game.
